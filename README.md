# Machine Learning Projects

A collection of practical **Machine Learning projects** covering supervised learning, regression, classification, model comparison, and real-world dataset analysis using Python and popular machine learning libraries.

The repository demonstrates the complete machine learning workflow, from **data preprocessing and exploratory data analysis to model training, evaluation, and comparison**.

---

## 📌 Projects

### 🏠 1. California Housing Price Prediction

A regression project focused on predicting housing prices using the **California Housing dataset**.

**Key topics:**

* Exploratory Data Analysis (EDA)
* Data preprocessing
* Feature analysis
* Regression modeling
* Model evaluation
* Prediction of continuous target values

**Notebook:** `california-housing-price.ipynb`

---

### 🫁 2. COVID & Pneumonia Classification

A classification project for identifying medical conditions from chest X-ray images.

The project explores machine learning/deep learning techniques for distinguishing between different classes such as COVID-19 and pneumonia.

**Key topics:**

* Image preprocessing
* Image classification
* Training and validation
* Classification metrics
* Model evaluation

**Notebook:** `covid_pneumonia_classification.ipynb`

---

### ❤️ 3. Heart Disease Prediction

A supervised machine learning project that predicts the likelihood of heart disease based on patient-related features.

**Key topics:**

* Data preprocessing
* Exploratory Data Analysis
* Feature analysis
* Binary classification
* Model training
* Performance evaluation

**Notebook:** `heart disease.ipynb`

---

### 🏡 4. Housing Price Prediction — Model Comparison

A comparative regression project using multiple machine learning algorithms to predict housing prices.

The project explores and compares:

* **Linear Regression**
* **K-Nearest Neighbors (KNN)**
* **Decision Tree Regression**

**Key topics:**

* Regression
* Feature preprocessing
* Multiple model training
* Hyperparameter experimentation
* Model comparison
* Evaluation metrics

**Notebook:** `housing-price-prediction-using-linear-regression,knn and decision tree.ipynb`

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Abdelrahman2572002/machine-learning-projects.git

cd machine-learning-projects
```

Install the required libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn tensorflow jupyter
```

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open any notebook and run the cells sequentially.
